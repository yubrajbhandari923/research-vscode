# Build a source-grounded literature map

1. Define the technical claim, keywords, competing methods, and inclusion/exclusion criteria. Separate foundational literature from current state of the art.
2. Search available scholarly sources and retrieve the actual paper or authoritative abstract. Verify title, authors, date, DOI/arXiv identity, and the precise result before citing it.
3. For each relevant work, extract the setup, assumptions, input/output modalities, datasets, evaluation protocol, and what the authors **actually demonstrate**.
4. Compare to the proposed method in a compact matrix: same problem? same information available? same evaluation? same limitations? This is critical for identifiability and data-leakage claims.
5. Classify statements as directly supported, plausible extrapolation, or unknown. Record contradictory papers and negative results.
6. Save trustworthy references using the project's existing citation workflow, not invented BibTeX. Where the source cannot be accessed, label the comparison provisional.
7. Produce the few papers worth reading deeply and the experiment that would most clearly establish novelty.

Do not cite a search snippet as if a full methods section was read. Do not claim a paper solves a problem merely because its title sounds similar.
